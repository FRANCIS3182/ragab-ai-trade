# Ragab AI Trade - Website Files

This directory contains the complete website for Ragab AI Trade automated trading platform.

## 📁 Files

- **index.html** - Main landing page with complete website structure
- **styles.css** - Professional responsive styling and animations
- **script.js** - Interactive JavaScript functionality

## 🚀 How to Deploy

### Option 1: GitHub Pages (Recommended)
1. Go to repository Settings → Pages
2. Select "Deploy from a branch"
3. Choose "main" branch and "/" root
4. Click Save
5. Your site will be live at: `https://FRANCIS3182.github.io/ragab-ai-trade/`

### Option 2: Local Testing
1. Open `index.html` directly in your browser
2. Or use a local server:
```bash
# Python 3
python -m http.server 8000

# Then visit: http://localhost:8000
```

### Option 3: Deploy to Web Host
- Upload the three files (index.html, styles.css, script.js) to any web hosting service
- Popular options: Netlify, Vercel, Firebase Hosting, etc.
